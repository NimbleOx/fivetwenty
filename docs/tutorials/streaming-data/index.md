# Real-time Streaming Data Tutorial Series

Learn real-time market data streams, implement live trading systems, and build sophisticated market monitoring applications through this comprehensive tutorial series.

---

## Prerequisites

- Completed [Basic Trading Tutorial](../basic-trading/index.md)
- Understanding of async programming in Python
- FiveTwenty setup with live data access
- Knowledge of real-time system concepts

---

## Tutorial Series Overview

Learn real-time data streaming through progressive, focused tutorials:

### **1. [Streaming Fundamentals](streaming-fundamentals.md)**
**Understanding the basics of real-time market data**
- Types of streaming data (price, account, transaction)
- Key concepts: heartbeats, reconnection, backpressure
- Streaming architecture and patterns
- Connection management principles

### **2. [Basic Streaming Implementation](basic-streaming.md)**
**Implement your first real-time data streams**
- Price stream setup and configuration
- Account change monitoring
- Basic data handling and processing
- Error handling and reconnection

### **3. [Automated Trading](automated-trading.md)**
**Build complete automated trading systems**
- Live trading engine architecture
- Order management with streaming data
- Risk management integration
- Performance monitoring and alerting

### **4. [Advanced Streaming Features](advanced-features.md)**
**Implement sophisticated streaming capabilities**
- Connection management and error recovery
- Advanced reconnection policies
- Stream multiplexing and aggregation
- High-availability streaming systems

---

## Learning Path

**Recommended Order:**
1. Start with **Streaming Fundamentals** for conceptual understanding
2. Build **Basic Streaming** implementation
3. Deploy **Automated Trading Systems**
4. Add **Advanced Streaming Features**

**Estimated Time:** 8-10 hours total (1-1.5 hours per tutorial)

**Prerequisites Check:**
- ✅ Async/await programming knowledge
- ✅ FiveTwenty SDK configured with streaming access
- ✅ Python environment with real-time libraries
- ✅ Understanding of market data concepts

## Key Concepts Covered

- **Real-time Data Processing**: Handle continuous market data streams
- **Stream Management**: Connection handling, reconnection, and error recovery
- **Data Aggregation**: Real-time windowing and buffering techniques
- **Signal Generation**: Live technical analysis and event detection
- **Trading Integration**: Automated decision-making from streaming data
- **Production Systems**: Scalable, reliable streaming architectures
