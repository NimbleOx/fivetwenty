# API Reference Models Documentation Review Plan

## Objective
Review Pydantic model documentation in `docs/api-reference/models/`

## Process

1. **Review Documentation Structure**:
   - Link to OANDA docs (🔗 prefix on link line)
   - Link to GitHub source (🔗 prefix, use `https://github.com/NimbleOx/fivetwenty/...`)
   - Section order:
     1. Title (e.g., `## Trade`)
     2. Brief description
     4. Links (OANDA, FiveTwenty SDK)
     5. Fields table (Field | Type | Required | Description)
     6. Notes (optional - validation rules, special behaviors)
2. **Pause**: Wait for user approval
3. **Commit**: Concise commit message per file
